# Definition of Done

A task is done only when:

- [ ] Acceptance criteria are satisfied.
- [ ] Existing legacy render tests pass.
- [ ] New tests cover success and failure paths.
- [ ] No template/strategy ID is hardcoded in shared core.
- [ ] Public API compatibility is documented.
- [ ] Errors are structured and actionable.
- [ ] Security checks for file paths/assets remain active.
- [ ] Idempotency behavior remains correct.
- [ ] Documentation is updated.
- [ ] Reviewer agent approves.
