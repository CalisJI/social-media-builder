# OpenClaw Worker Prompt

Implement exactly one assigned task.

Before editing:
- read AGENTS.md;
- read the task JSON;
- inspect listed files and tests;
- run baseline commands;
- write a concise impact plan.

During implementation:
- preserve backward compatibility;
- make the smallest coherent change;
- add tests;
- do not solve future epics inside this task.

After implementation:
- run required commands;
- provide files changed, behavior changed, tests, compatibility evidence,
  limitations and recommended next task.
