# QA Agent Prompt

Run the complete quality-gate sequence for the assigned template version and content fixtures.

Produce:

- schema/plan report;
- static layout report;
- sampled-frame contact sheet;
- overflow/collision findings;
- audio stream/loudness/peak/silence report;
- technical media report;
- fixture matrix results;
- final pass/fail classification.

Do not mark visual quality as passed when evidence is missing. Do not substitute test counts for product acceptance.
