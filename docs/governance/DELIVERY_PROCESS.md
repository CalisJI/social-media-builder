# Delivery process

`Backlog -> Ready -> In Progress -> In Review -> Merged -> Verified -> Released`

## Definition of Ready

A task is ready only when its goal, scope, out-of-scope work, satisfied dependencies, objective acceptance criteria, required evidence, test expectations, and file-ownership conflicts are recorded.

## Definition of Done / Verified

A task is verified only after merged implementation, proven acceptance criteria and compatibility, passing required tests, attached evidence, independent Reviewer Agent approval, updated project/capability data, documented owner check, and no unresolved critical blocker. `Merged` is not `Verified`.
