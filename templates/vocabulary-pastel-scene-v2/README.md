# Vocabulary Pastel scene-v2

Declarative scene-v2 parity package for `vocabulary-pastel-v1`. It is additive:
legacy pastel jobs continue to use `vocabulary-pastel-v1` and `legacy-v1`.

`manifest.json` is the package's presentation configuration: its named palette
tokens, layout constraints, timeline, assets, and declarative scene are the only
source of template behavior. `fixtures/` contains the mandatory preview inputs.
See `VISUAL_COMPARISON.md` for the parity decision and remaining engine limits.
